# Skills do projeto

## codemakers-design

Pacote de design front-end enviado pelo cliente (versão 2.1.0, criada por Bueno,
da Code Makers). Carrega sozinho em sessões do Claude Code neste repositório.

Usado neste site para:

- direção de assets (enquadramento das fotos do topo e do capítulo);
- verificação de contraste com `scripts/contrast_check.py`.

A marca Code Makers identifica a skill e **não** deve aparecer no site do cliente.
